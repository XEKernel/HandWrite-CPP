命令行

GUI 之外，CLI 更直接

适合批处理、脚本自动化、远程服务器

基本用法bash
# 从命令行参数生成 PNG
handwrite-cli \
  -t "今天天气真好。" \
  -o "F:/out" \
  -f png \
  -r 2

# 输出 PDF / SVG
handwrite-cli -t "..." -o out -f pdf
批量与预设bash
# 加载预设参数（字体、扰动、纹理等）
handwrite-cli -i essay.txt -p my.conf

# 从文件读取待生成文本列表
# batch.txt: 每行一个文本，自动产出 0.png 1.png ...
handwrite-cli --batch batch.txt

# 支持从剪贴板读取
handwrite-cli --clipboard -o out
