### 修复过程中新发现、原报告未列出的 2 个 BUG（重要）

1. **预设小数被静默截断成整数**（`config.cpp`）：`std::stoi("0.35")` 只解析前导 `0` 就返回**且不抛异常**，
   所以旧代码 `try { m_data[k]=std::stoi(v); } catch(...)` 从不走到 `stod`，
   导致 `font_mix_rate`/`texture_opacity`/各 `*_sigma` 等**所有小数参数保存后再加载全变 0**。
   修法：必须 `pos == value.size()`（整串被消费）才算数字。已加回归断言。
   → 教训：**任何用 stoi 判类型的代码都要检查 pos**，这是 C++ 的经典陷阱。
2. **注释行末反斜杠吞掉下一行代码**（`config.cpp` `escapeString` 上方）：
   `// 写文件时转义 " 与 \` 末尾的 `\` 让函数定义变成注释 → 整个 `Config` 类作用域错乱。
   由新开的 `-Wall`（`-Wcomment`）报出。**注释里不要以反斜杠结尾。**
