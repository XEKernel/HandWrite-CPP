需求：增加横线定义能力，让文字排布在横线内。**明确说「暂时不开工」，只出规划。**

产物：`docs/PLAN_LINE_GUIDES_2026-09-13.md`

### 调研出的核心技术点（这是本需求的关键，务必记住）

- **三个坐标空间**：
  A = 背景原图坐标（`BackgroundCalibration::gridPoints` 存这里，core.hpp:102）
  B = 渲染画布坐标（`scaledWidth × scaledHeight`，`lineYPositions` 用这个）
  C = warp 源平面 —— 校准模式下文字**实际被画的平面**，是一张 rows×cols 的**均匀网格**（core.cpp:1049-1056）
- `warpMesh`（core.cpp:1505）做的是 **C → B 的分片 quadToQuad**，
  即「文字先画在均匀平面 C 上，再整体被掰弯贴到画布 B 上」。
- 因此「让文字落在照片横线内」有两种完全不同的算法：
  - **无校准**：A→B 只是线性缩放，横线还是直线 → 直接把行 Y 设成横线 Y，**简单**
  - **有校准**：横线在 B 里是弯的（透视），但文字画在 C 上
    → 必须把横线 **从 B 逆映射回 C**（`QTransform::quadToQuad(dstQuad, srcQuad, inv)`，
    注意参数顺序与 warpMesh 相反），在 C 上按折线排字，**复杂**

### 顺带发现的现状不一致（开工时一并修）

`alignToGrid = (paperTexture != None)`（core.cpp:635）与是否校准无关，
但校准模式下 `drawPaperTexture` 被跳过（core.cpp:941）。
→ 同时开「纹理」+「背景图锚点」时，行仍在按纹理网格吸附，但纹理没画、文字还要再 warp 一次，得到无意义位置。
规划：Line Guide 启用时强制 `alignToGrid=false`。

### 规划要点

- 建议方案：**手动等分打底**（画 2 条边界线 + 填条数，4 次点击），自动检测作为后续增强
- 基线用 `baselineRatio`（默认 0.82）+ 像素微调，不能硬编码
- 每行跟随横线倾斜（`followTilt`）是"贴合照片"的关键
- 分 5 批：1 数据+无校准对齐 → 2 倾斜+UI → 3 校准联动(逆映射) → 4 自动检测 → 5 作文格/竖排扩展
- **建议先只做 1+2**，逆映射是唯一有真实风险的部分，而正拍/轻斜拍占绝大多数场景
- 自动检测用「逐行暗像素占比 → 峰值 → **等距规则化补齐**」，等距规则化是鲁棒性主要来源
- 不涉及新依赖（不引 OpenCV）

## 规划 v2 修订（同日，按用户反馈重写）

用户补充两点，直接推翻了 v1 的两条核心假设：

1. **纸张会弯曲 → 照片上的横线是弯的**，所以横线必须手绘，不能假设直线/两点式
2. **流程固定为：先锚点定透视 → 再在照片上画横线 → 文字按横线排布**

由此产生的**路线变更（重要）**：

- v1 方案是「把 guide 从画布 B 逆映射回 warp 源平面 C，在 C 上排字，warp 回 B」
- v2 **放弃逆映射**，改为 **bypass warpMesh，在画布 B 上逐字沿曲线直接绘制**

理由：guide 曲线是用户在**照片（B 空间）上描出来的**，本身就已包含透视 + 弯曲的全部形变。
逆映射 B→C 再 warp C→B 理想情况下恒等，实际因 `quadToQuad` 分片近似 + 锚点网格常见只有 3×3
（表达不了高频弯曲）**反而引入误差**。直接画才是精确的：用户画的线在哪，字就走哪。

### 新发现的关键事实（决定改造量）

`drawTextWithPerturbationStatic`（core.cpp:755-897）**内部本来就是逐字循环**，
每字符都有 `save` / `translate` / `rotate` / `drawText` / `restore`（core.cpp:843-890）。
所以"逐字沿曲线走"只需在循环内按当前 x 采样曲线，叠加 y 偏移与切线角 —— **改造量很小**。
这比 v1 的逆映射方案简单得多，是本次路线变更的最大收益。

### 锚点是否还需要 → 需要，两者分工正交

- **锚点**：页面几何（文字块四角、水平起止 x、整体包围盒）—— 低频整体透视
- **guide curve**：行级细节（每行文字走哪条曲线）—— 高频纸张弯曲

锚点网格 3×3 表达不了弯曲，所以必须单独画横线；但四角定位仍靠锚点。

### 交互关键：关键曲线 + 弧长插值

20+ 条横线逐条画不现实。因为纸张弯曲是连续形变，
**画 2 条（首、尾）关键曲线 + 填条数 → 中间按弧长参数插值**即可；
中间鼓起时再画 1 条中间关键线 → 分段插值。交互成本从 20 条降到 2~3 条。
